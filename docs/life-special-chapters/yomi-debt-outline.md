# 《沉命余赊篇》剧情大纲 v0.2

> 别名：黄泉债篇
> 篇章 ID：`yomi_debt`
> 入口事件：`p_yomi_receipt / 沉命余赊`
> 触发条件：`yomi_debt >= 2`
> 核心类型：死亡延期、账本怪谈、温柔债务、黑深残式偿还。
> 叙事目标：让玩家意识到，活下来不是免费奖励；每次侥幸都曾从某处扣款。

## 一、风格重定向

新版《沉命余赊篇》不应写成“阴间办事大厅”这么简单。它要更像一卷冷色调的黑暗轻小说：空间规则清楚，窗口对白克制，角色看似温柔，最后让玩家发现最残忍的不是死亡，而是“你活着这件事可能一直由别人付款”。

本篇的恐怖感来自行政化、礼貌化和延迟化。

- **行政化**：死亡被写成编号、收据、延期申请、柜台回执。越冷静，越残忍。
- **礼貌化**：窗口人员不会威胁玩家，只会耐心解释条款，让玩家自己签字。
- **延迟化**：拒绝偿还不会立刻死亡，只会滚入下一期；玩家越晚处理，牵连的人越多。

本篇不能只表现“你欠死亡”。更重要的是表现“你的债可能不在你名下”。这是黑深残核心：玩家的幸运不是天降，而是有人在看不见的地方被扣除了未来。

## 二、黄泉债的本质

黄泉债不是阴曹地府的惩罚，也不是数值系统的包装。它是所有“本该结束但没有结束”的人生差额。

玩家曾经从冰面裂缝、病房心跳归零、废井替身、潮水、车祸、火灾或毒雾中活下来。现实只记录“幸存”。黄泉柜台记录的是另一件事：

```text
本次死亡已延期。
延期来源：未确认。
付款人：待核验。
```

这意味着玩家每次濒死后继续活着，都可能有三种来源：

1. 未来的自己提前支付寿命或身体余量。
2. 关系中的某个人替玩家承担厄运。
3. 某个不被现实承认的版本替玩家签字。

因此，本篇不是清算罪恶，而是清算“侥幸”。

## 三、世界舞台：延期柜台

黄泉债篇的空间叫“延期柜台”。它不像地狱，更像深夜医院缴费处、旧银行、派出所户籍窗口和无人车站的混合体。

视觉关键词：

```text
湿地砖、苍白灯管、叫号机、玻璃窗口、红色印泥、旧式算盘、被水泡皱的收据、永远排不到尽头的队。
```

这里没有哭喊。所有人都安静等号。每个人手里都拿着一张收据，有的人收据上写着“病故延期”，有的人写着“坠落延期”，有的人写着“被遗忘延期”。叫号机不会叫名字，只叫死亡方式。

```text
请“十七岁夏季溺亡延期”到三号窗口。
请“井下替身签收异常”到七号窗口。
请“朋友代偿未确认”到复核室。
```

窗口后的人没有明显恶意。他们称玩家为“延期人”，语气始终礼貌：

```text
您不用害怕。
死亡没有取消，只是改了付款方式。
```

## 四、入口事件：湿收据

`p_yomi_receipt / 沉命余赊` 触发时，玩家连续几夜梦见一张湿透的收据。收据金额栏不是数字，而是一排日期。每个日期都对应一次玩家差点死掉的事件。

第一夜，玩家看不清字，只觉得手心发冷。
第二夜，收据出现在枕头下，醒来后没有纸，但掌心有红色印痕。
第三夜，梦中的叫号机响起：

```text
请“尚未承认自己欠债的人”到窗口。
```

玩家可选择：

- 按下手印，查看欠账：进入黄泉债篇，写入 `yomi_receipt_seen`。
- 撕掉收据：不进入篇章，但 `yomi_debt` 增加，代表拒绝承认。
- 把收据藏起来：后续可接更深的“复利债”分支。

入口要让玩家感到：进入篇章不是被强制拖走，而是终于承认自己早已被登记。

## 五、四幕结构

## 第一幕：窗口后的人认识你

玩家来到延期柜台。窗口后的人看见玩家，没有问姓名，只递出一支笔。

```text
您终于来了。
请先确认：您是否承认自己仍然活着？
```

这是第一幕核心钩子。玩家以为对方要确认死亡，对方却要求确认“活着”。因为在黄泉账本里，活着不是自然状态，而是一项需要来源证明的支出。

关键节点：

- `c_yomi_counter / 持命验赊`：查看第一笔延期。
- 第一笔账通常对应一次早期事故，备注写着“从未来体力中扣除”或“由未登记关系代付”。
- 玩家可以询问能否一次结清。窗口回答：“可以。但结清后的您，未必还适合回去。”

本幕要建立本篇的冷静恐怖：没有威胁，只有手续。

## 第二幕：三份档案

柜台递出三份档案：

1. **玩家档案**：记录玩家所有濒死瞬间。
2. **狗子档案**：记录狗子曾经替玩家做过的签收。
3. **空白档案**：没有姓名，只有一枚湿手印。

`c_yomi_three_records / 沉门映册` 是本篇中段核心。玩家翻开哪份档案，决定后续理解债务的方式。

### 玩家档案

里面的死亡瞬间像被水泡烂的照片。照片里玩家每次都差一点死去，但每张照片边缘都有另一个人的手、影子或名字。玩家以为自己是主角，档案却显示每次“主角光环”都来自某个具体的付款人。

### 狗子档案

狗子的档案并不厚，但每一页都被反复翻过。里面写着：

```text
代签次数：无法统计。
身份状态：部分留井。
备注：本人多次要求删除玩家知情权。
```

这会把黄泉债篇与沉没异生篇、犬鸣线连接起来。狗子不是单纯朋友，而是多次把玩家从结局里往回拖的人。

### 空白档案

空白档案最危险。它代表“无人记得的人生”。当玩家翻开它，空白页会浮出玩家自己的笔迹：

```text
如果没人记得，就不算活过。
如果有人替你记得，他就要替你付账。
```

## 第三幕：偿还不是选择题，是切除术

黄泉债提供三种偿还方式。它们都有效，但都不是好结局。

### 方式一：记忆偿还

玩家可以剪掉一段童年记忆。不是删除事实，而是删除情感温度。现实里旧照片还在，玩家知道照片里的人是自己，也知道那天大概很快乐，但再也想不起为什么快乐。

对应节点：`c_yomi_memory_tax / 偿梦遗失`。

代价表现：

```text
你没有忘记那年夏天。
你只是再也无法证明，自己曾经期待过它。
```

### 方式二：关系偿还

玩家可以用一段关系抵债。对方不会消失，也不会死亡，只是某句本该重要的话永远变轻。聊天记录仍在，但读起来像别人写的。关系不是断裂，而是失去重量。

对应节点：`c_yomi_relationship_tax / 持梦约损`。

代价表现：

```text
你们仍然认识。
只是从此以后，所有“我在”都像客套。
```

### 方式三：继续延期

玩家可以拒绝偿还，把债滚入下一期。系统不应立刻惩罚，而应让后续人生更频繁地遇到濒死、井、狗子、错名、空白档案。拒绝不是逃脱，而是把代价转交给未来。

对应扩展：`yomi_debt` 增加，未来触发更深追债。

## 第四幕：最后一笔债不是你的名字

当玩家要求查看最后一笔债，窗口后的灯全部熄灭，只剩一盏红灯。账本翻到最后一页。那里写着一个熟悉的人名。

这个名字可以根据前置 flag 变化：

- 若沉没异生篇中信任狗子：最后一笔债更可能指向狗子。
- 若替身上岸：最后一笔债指向替身。
- 若多次拒绝偿还：最后一笔债指向“未来的自己”。
- 若关系线深：最后一笔债指向知己或伴侣。

本幕不是让玩家震惊“我要死”，而是让玩家意识到：自己继续活着，可能一直在消耗某个亲近者的余量。

对应节点：`c_yomi_substitute / 沉名易身`。

玩家选择：

- 把债转回自己名下：身体变沉，体质下降，但解除他人牵连。
- 假装没有看清名字：回到现实，短期安全，但留下更深阴影。
- 要求共同承担：后续可扩展为关系特殊终局。

## 六、黑深残式反转链

### 反转一：黄泉不讨命，只讨证明

玩家以为自己要被死亡索取。结果柜台要求他证明“你为什么仍然活着”。这把恐怖从外部惩罚转为存在审计。

### 反转二：债务不是数字，而是被切薄的人生

每次偿还都不会直接杀玩家，但会削薄记忆、关系、名字、好运。玩家仍然活着，却越来越像一个被合法删减过的人。

### 反转三：最重的债往往由最温柔的人代签

狗子、替身、未来自己、知己，这些不是道具。他们是账本上的付款人。本篇的残酷点不是“有人为你牺牲”，而是“他们可能在你不知情时已经牺牲过很多次”。

## 七、蒙太奇设计

### 1. 死亡延期蒙太奇

叫号机每响一次，玩家看见一个被改写的死亡瞬间：

- 冰面裂开，水下有一只手把玩家推上去。
- 废井深处，另一个自己替玩家答到。
- 病房心电图拉直，又被红印盖回波形。
- 车灯撞来前，狗子的声音喊了一句“这次不行”。
- 老年走廊尽头，未来的自己把一张收据塞回门缝。

每个片段都只有一秒。玩家无法确认谁救了自己，但每个片段都在账本里产生一行记录。

### 2. 偿还现实蒙太奇

玩家交出记忆后，旧照片仍在，但照片背面的字变成空白。
玩家交出关系后，手机联系人还在，但备注变成系统默认姓名。
玩家把债转回自己名下后，某个熟悉的人睡得安稳，玩家醒来时胸口像压着湿纸。
玩家拒绝偿还后，窗外有人排队，队伍里每个人都拿着玩家签过的收据。

### 3. 最后一页蒙太奇

账本最后一页不是静态文本，而是连续变换的名字。狗子、替身、未来自己、母亲、知己。最后名字全部被水泡开，只剩一句：

```text
付款人并不重要。
重要的是，您是否愿意知道。
```

## 八、结局方向

### 结局 A：《出命又生》——带债归来

玩家确认账本，但没有彻底偿还。回到现实时，床头有一张不存在的收据，上面写着“下次见”。这是普通回流结局，适合让人生继续推进。

### 结局 B：《偿梦遗失》——记忆抵债

玩家用记忆偿还一部分债。人生继续，但某段情感被合法切除。结算时可表现为：事件仍在日志里，但描述变冷。

### 结局 C：《持梦约损》——关系抵债

玩家用关系抵债。知己或重要关系没有消失，但亲密感永久变薄。这个结局应当让玩家后悔，不是因为数值损失，而是因为“还在”比“失去”更钝痛。

### 结局 D：《沉名易身》——债回己身

玩家看见最后一笔债牵连他人，选择转回自己名下。短期体质下降，长期解除更坏结局。这不是胜利，而是把账本从别人怀里拿回来。

### 结局 E：《无人记得》——拒偿扩展终局

如果玩家多次撕毁收据、拒绝偿还、假装没看清名字，最终触发。玩家没有死，但现实开始删除他与他人的连接。结算页中成就还在，关系还在，事件还在，只是每个名字都变成“某人”。

最后文本：

```text
死亡没有追上你。
它只是把所有记得你的人，
一个一个请到了窗口前。
```

## 九、事件节点重写方向

```text
p_yomi_receipt          强化湿收据与叫号机钩子
c_yomi_counter          强化“确认自己仍然活着”的存在审计
c_yomi_three_records    强化三份档案的角色指向
c_yomi_memory_tax       强化记忆不是删除事实，而是删除温度
c_yomi_relationship_tax 强化关系仍在但变轻的钝痛
c_yomi_return           强化带债回归的后续阴影
c_yomi_substitute       强化最后一笔债牵连熟人的反转
```

## 十、情绪目标

玩家完成本篇后，应当重新理解所有“侥幸活下来”的瞬间：

```text
我没有战胜死亡。
我只是暂时没有看见付款人。

如果我还要继续活，
至少这一次，
我要知道账单寄给了谁。
```

这就是《沉命余赊篇》的核心余痛。
