# 《沉没异生篇》剧情大纲 v0.3

> 篇章 ID：`well_otherworld`
> 入口事件：`p_kid_well / 沉没影深`、`p_kid_well_dream / 沉梦又深`
> 核心类型：童年怪谈、黄泉异界、平行人生、替身上岸、黑深残式代价链。
> 叙事基调：轻小说式强钩子 + 日常物件恐怖 + 温柔角色反噬 + 选择后果延期。
> 叙事目标：让玩家不是“探索一个井下副本”，而是意识到——自己放弃的选择仍在别处活着，并且一直等着上岸。

## 一、风格重定向

新版《沉没异生篇》不再只是“井下有另一个世界”。它应当更像一卷带插画感的黑暗轻小说：开头用清晰、抓人的奇观钩住玩家，中段用可爱的日常细节慢慢腐烂，后段让玩家发现此前所有温柔提示都不是保护，而是账单。

本篇的黑暗不能只靠血腥、死亡或怪物完成。真正的压迫感来自三点：

1. **日常被轻微改写**：教室座位、作业本、母亲喊名、狗子的口头禅都还在，但总有一个字、一个人或一个影子不对。
2. **希望具有副作用**：每条逃生路都有效，但都会留下一个人、一段记忆或一个名字。
3. **角色比规则更可怕**：井下书记官很礼貌，狗子很可靠，另一个自己很可怜；正因为他们不像怪物，玩家才更难拒绝他们。

玩家应当在前半段觉得“这条线神秘又迷人”，在中段觉得“我好像理解规则了”，在后段发现“规则从来不是给我逃出去用的，而是用来计算谁替我留下”。

## 二、核心设定：井不是入口，而是回收站

废井并不通往地下。它通往“未被人生采用的分支”。

玩家每一次没有说出口的话、没有走下去的路、没有选择的人，都会沉到井下。井下世界因此长得像故乡：小学、巷口、小卖部、雨棚、楼梯间、老槐树、母亲的围裙、狗子的旧校服。它不是为了欺骗玩家，而是因为玩家的可能性只能用玩家熟悉的东西重组。

井下世界的居民分三类：

### 1. 无影居民

他们是被现实遗忘的可能性。没有影子，没有完整名字，讲话像旧磁带反复倒带。大多数人没有恶意，只是习惯向每个“还带着影子的人”借一点存在感。

### 2. 井下狗子

他看起来像现实中的狗子，但年龄不稳定：有时是小学同桌，有时像成年后的朋友，有时又像已经死过很多次的人。他的口头禅是：

```text
别问我为什么知道。
你每次问到这里，我都要重新决定要不要骗你。
```

狗子不是导师。他是轮回中最接近玩家的人，也是最会隐瞒的人。他多次救玩家，但每次救人都会把自己的一部分留在井下。玩家越信任他，越接近真相；越接近真相，越可能发现他并不总是站在“玩家本人”这一边。

### 3. 替身

替身不是假玩家，也不是恶灵。它是某条被废弃人生中继续长大的“另一个你”。它知道玩家的童年，知道玩家没说出口的愿望，也知道玩家后来会怎样变得疲惫。它想上岸，不是为了伤害玩家，而是因为它也认为自己有资格活一次。

这使替身线具有黑深残核心：玩家面对的不是敌人，而是一个同样拥有痛苦和记忆的自己。

## 三、世界规则

### 规则一：名字是现实的锚

名字不是称呼，而是现实承认你存在的坐标。井下交易不收钱，只收名字的一部分。

玩家交出名字中的一个字后，短期会得到出口、好运、才能、死亡延期或某种剧情便利。长期代价是现实开始发生错位：母亲叫错名字，成绩单缺字，聊天记录里称呼变成空格，结算回顾中玩家姓名偶尔被替换成“那孩子”。

### 规则二：影子是上岸资格

有影子的人才能回现实。玩家刚进入井下时影子很重，所以无影居民会盯着他看。每多完成一次井下交易，影子就变淡。影子完全消失时，玩家仍能行动，但已经不再被现实优先承认。

### 规则三：回去必须留下等价物

井下没有免费出口。玩家可以留下名字、记忆、影子、关系中的一句话，也可以留下“一个人”。

最轻的代价是身体受伤；中等代价是现实称呼错乱；最重的代价是替身上岸或狗子留井。

### 规则四：越温柔的选择，结算越晚

本篇不应让所有惩罚立即出现。黑暗感来自延期。玩家在井下做出温柔选择时，结果文本可以先表现为被救、被理解、被放过；真正代价在后续事件、黄泉债篇或结算页才显现。

## 四、入口结构

### 入口 A：`p_kid_well / 沉没影深`

童年某日，孩子们围着废井玩“往下喊名字”的游戏。别人喊完只听见回声。玩家喊完后，井底传来狗子的声音：

```text
这次别下来。
我还没把你的座位擦干净。
```

玩家掀开井盖，看到井底没有水，只有一条干净的石阶。石阶上放着一只现实中早已找不到的红色橡皮，橡皮上刻着玩家名字中缺失的一个字。

选择结构：

- 掀开井盖：进入完整篇章，写入 `well_stair_seen`。
- 立刻逃走：暂时安全，写入 `well_refused_first`，未来触发梦井入口。
- 喊狗子的名字：不进入井，但狗子关系提前被井记录，未来解锁 `dog_memory` 分支。

### 入口 B：`p_kid_well_dream / 沉梦又深`

拒绝井口后，井开始追进日常。玩家在数学卷的圆圈里看到井盖，在洗手池排水口听见上课铃，在梦里走到学校负一层。负一层没有教室，只有一张课桌。桌上放着一张纸：

```text
你拒绝下井。
所以井决定上来。
```

这条入口用于表现“逃避不是终止，而是让异常日常化”。玩家可以进入梦井，也可以把梦写下来。写下来不进篇章，但会留下未来梦蚀类篇章接口。

## 五、三幕主线

## 第一幕：第十四阶不存在

玩家沿石阶向下走。每走一阶，上方伙伴声音就变化一次：童年、青春、成年、老年。第十三阶后，本应出现第十四阶的位置是一条街。

街道像故乡，但所有店铺都在卖不存在的东西：

- 小卖部卖“没被使用的压岁钱”。
- 文具店卖“写完就会被母亲忘记的名字贴”。
- 照相馆只拍没有影子的合照。
- 公交站牌不是地名，而是年龄：八岁、十二岁、十八岁、三十岁、临终。

本幕不急着解释规则，而是用轻小说式奇观制造吸引力。玩家会觉得“这里有系统、有谜、有可攻略角色”，但每个奇观都带一点不适。

关键节点：

- `c_well_stairs / 沉没幽深`：发现第十四阶之后不是井底，而是井下街。
- `c_well_market / 重门影市`：第一次看到人生片段被商品化。
- `c_well_empty_desk / 沉默余室`：教室最后一排多出的空桌，暗示“有人一直替你留座”。

核心选择方向：

- 立即上爬：短线回归现实，但留下井下回声。
- 继续深入：解锁学校和狗子线。
- 买下一段迟到的道歉：关系变暖，但未来某句真正的道歉会变轻。

## 第二幕：狗子说谎时会先笑一下

玩家进入井下学校。这里的恐怖不在血迹，而在“太像现实”。课表、座位、粉笔灰、窗外雨声都对。唯一不对的是黑板上写着玩家的名字，旁边用红笔加了一行：

```text
本日值日：替身。
```

狗子坐在最后一排。他第一眼看见玩家时先笑了一下，然后把笑收回去。这是本篇重要人物动作：狗子每次准备说谎，都会先笑一下。

他给玩家一张皱巴巴的纸，纸上不是地图，而是“之前轮回里玩家做过的选择”。有些选项被划掉几十次。最下面一行被水泡烂，只剩半句：

```text
上岸的人……
```

中段要强化角色关系，而不是只推设定。狗子会陪玩家穿过旧校舍，帮玩家躲开书记官，替玩家挡下无影居民的目光。他越可靠，玩家越应该害怕后面的真相。

关键节点：

- `c_well_school / 沉默影舍`：狗子登场，建立“他知道太多”的悬疑。
- `c_well_book / 残梦遗书`：纸条上的选择记录，形成轻小说式章节钩子。
- `c_well_montage / 错命映生`：多间教室展示不同人生版本。
- `c_well_dog_oath / 赤目约誓`：狗子承认有些轮回里是他替玩家留下。

本幕核心反转：狗子不是每次都在救玩家本人。有些轮回中，他救的是替身；有些轮回中，他故意让玩家回不去，因为那一轮上岸的玩家会伤害现实中的狗子。

玩家选择应当围绕信任和怀疑：

- 相信狗子：更容易回到现实，但可能不知道完整真相。
- 质问狗子：解锁替身真相，但关系受损。
- 偷看最后一行：进入替身线，后续结局变重。

## 第三幕：名簿上每一页都是你

街口书记官没有脸，但态度礼貌。他守着一本名簿。名簿每一页都写着玩家名字，每一页后面是一条人生路线。

第一页：没有掀井盖的你。
第二页：交出名字的你。
第三页：让狗子留下的你。
第四页：替身上岸后的你。
最后一页：空白。页脚写着：

```text
无人记得，也算活过吗？
```

书记官告诉玩家：井下不是惩罚装置，而是管理装置。现实只允许一个“你”继续被承认，其余版本必须沉下去。玩家之所以能站在这里，是因为之前已经有很多个自己替他沉没。

本幕将“探索”转化为“审判”：不是审判玩家善恶，而是审判玩家是否愿意承认自己活着靠牺牲别的可能性。

关键节点：

- `c_well_registrar / 持名欲失`：名字交易。
- `c_well_blank_name`：玩家发现名字缺字。
- `c_well_shadow / 尘幕映身`：另一个自己正式出现。
- `c_well_blank_substitute`：决定谁上岸。
- `c_well_stay / 沉没永生`：选择留下，社会性死亡。

## 六、黑深残式反转链

本篇需要至少三次反转，每次都不能只靠信息揭露，而要改变玩家对前面温柔事件的理解。

### 反转一：井下不是死亡世界，而是玩家人生的废稿箱

前期玩家以为这里是异世界。中段发现每个居民都与自己某个选择有关。井下不是外部怪谈，而是玩家人生内部的沉积物。

### 反转二：狗子不是单纯引路人，而是替玩家签过字的人

狗子记得轮回，不是因为他特殊，而是因为他曾多次替玩家留下名字、影子或死亡。玩家越依赖狗子，越会发现自己欠他越多。

### 反转三：替身不是敌人，而是被玩家活法挤掉的人

替身想上岸不是为了夺舍，而是因为它已经在井下替玩家上了很多年课、挨了很多年点名、长大了很多年。它不是假货。它是玩家没有活过但仍然痛苦的一生。

## 七、蒙太奇节点设计

### 1. 井下街灯蒙太奇

街灯每亮一次，玩家就看见一个圆形物件：井口、钟面、碗底、药瓶盖、病房灯、老年人手中的杯口。所有圆形最终叠成井口。狗子旁白：

```text
你以为井在童年。
其实它一直跟着你长大。
```

### 2. 替身人生蒙太奇

现实中的玩家在毕业照里笑。井下的替身在同一天被老师点名。现实中的玩家第一次工作。替身在井下便利店打夜班。现实中的玩家恋爱。替身在礼堂外把祝福写到纸上，又撕掉。现实中的玩家病危。替身在黄泉柜台前替他按下手印。

最后镜头回到教室。替身问：

```text
如果我替你痛过，替你怕过，替你长大过，
那我到底是不是你？
```

### 3. 狗子轮回蒙太奇

每一轮狗子都来晚一点：第一次拉住玩家，第二次只抓住袖口，第三次只捡到姓名贴，第四次只在空桌前坐到天亮。最后一轮，他提前坐在井口，说：

```text
这次我不救你了。
我要先问问你，准备救谁。
```

## 八、结局方向

### 结局 A：《出梦又生》——轻伤上岸

玩家保留名字和影子，付出身体伤害或轻微记忆错位，回到现实。该结局适合普通完成，不应过难。余痛是：现实里的井被封住，但玩家偶尔会在玻璃倒影里看到第十四阶。

### 结局 B：《持名欲失》——缺字归乡

玩家交出名字的一部分换取出口。现实继续，但所有亲密称呼开始错位。母亲会在饭桌上停顿，老师会念错点名，恋人会把备注改成一个空格。这个结局不杀玩家，而是让玩家逐渐变成“仍活着但不完整的人”。

### 结局 C：《赤目约誓》——狗子带路

玩家相信狗子。狗子带玩家穿过雨幕，上岸前把自己的影子借给玩家。现实中玩家醒来，手里有一张纸：

```text
这次先别找我。
我怕我又会答应你。
```

狗子关系提升，但未来犬鸣线、黄泉债线会更重。

### 结局 D：《沉名易身》——替身上岸

玩家让另一个自己上岸。现实不立刻崩坏。只是玩家发现某些事件回忆开始变成第三人称。“我考上大学”变成“那个人替我去了远方”。后续触发 `yomi_debt`，因为现实承认了一个不该同时存在的名字。

### 结局 E：《沉没永生》——井下留名

玩家选择留下。现实中他被判定失踪。井口被封住那天，井下学校举行转学生欢迎会。老师点名时喊出一个陌生名字，玩家站起来答到。结算不应只是死亡，而是社会性死亡与身份转籍。

### 结局 F：《无人记得》——隐藏扩展结局

若玩家多次交出名字、拒绝偿还黄泉债、让替身承担后果，最终可以触发。玩家仍在现实活着，但回顾页中关键人物不再记得他。成就、关系、事件日志像被雨水泡过。最后一行：

```text
你没有死。
只是世界不再需要证明你来过。
```

## 九、事件节点重写方向

已存在节点不必全部改结构，但文案应按以下方向增强：

```text
c_well_stairs       强化“第十四阶不存在”的第一钩子
c_well_school       强化狗子的动作、口癖和隐瞒
c_well_registrar    强化名字交易的行政恐怖感
c_well_book         强化纸条记录旧轮回选择
c_well_montage      强化多人生教室剪辑
c_well_shadow       强化替身的非恶意诉求
c_well_dog_oath     强化狗子曾替玩家留下的债
c_well_blank_name   用空标题表现名字缺失
c_well_blank_substitute 用空标题表现真正终局选择
```

## 十、情绪目标

玩家完成本篇后，应当留下这样的心理残响：

```text
我回来了。
可回来的凭证，不全是我的。
有人替我坐在最后一排，
有人替我保管没选的人生，
有人在井底继续用我的名字答到。
```

这不是“逃出井底”的胜利，而是“带着被替换的罪感继续活着”。
