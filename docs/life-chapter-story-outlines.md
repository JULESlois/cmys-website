# `/life` 篇章树剧情大纲 v0.1

> 用途：为 `/life` 的篇章树系统提供剧情方向、触发器、分支结构、结局类型与可转化为事件的数据草案。本文不是最终事件文本，而是后续编写 `chapters.ts` 与篇章事件数据的剧情蓝图。

## 0. 参考母题与改造原则

本大纲借用公开民俗与类型叙事母题，但不直接复刻既有作品：

- **神隐 / Kamikakushi**：人被神或灵隐藏，返回现实后身份发生变化。适合转化为“消失数日、现实只过去一瞬、社会性死亡后复归”。
- **黄泉 / Yomi**：地下、死亡、污秽、返回代价。适合做“井下世界”和“死亡边缘交易”。
- **稀人 / Marebito**：远方或异界来访者，既是客人也是神。适合做“陌生人、转学生、来访者、无影客”。
- **付丧神 / Tsukumogami**：器物因漫长使用而拥有灵性。适合做“旧物、遗物、手机、棋子、校服、抽卡卡牌开始说话”。
- **龙宫 / 浦岛式时间错位**：海底宫殿与时间差。适合做“海渊篇”的时间错位与迟归代价。
- **空舟 / Utsuro-bune**：未知空舟、异乡女子、无法沟通的漂流物。适合做“海上漂来的空舱”与“异界信息”。
- **都市传说**：可信细节 + 不可信事件的张力。适合 `/life` 的现实裂缝风格。
- **宇宙恐怖**：不是怪物跳脸，而是“人类理解不了的秩序正在注视你”。适合梦境、深海、病院和创作污染。
- **异世界 / Isekai**：不是单纯转生冒险，而是“人生失败点后的第二系统”。适合把即死事件变成隐藏分支。

改造原则：

```text
现实先成立，异常再渗入。
异常不直接解释，先留下后果。
每个篇章至少有 2~3 条分支。
每个篇章都能回到现实，也能导向特殊结局。
死亡不是唯一惩罚；失忆、替身、欠债、被记住、被交换同样是代价。
```

## 1. 全局篇章树结构

### 1.1 表层主线

玩家仍然沿着现实人生推进：

```text
婴幼期 -> 少年期 -> 青年期 -> 壮年期 -> 晚年期 -> 死亡/结算
```

篇章树不替代这条线，而是在特定事件中插入隐藏分支。

### 1.2 隐藏变量

建议新增以下全局 flag：

```ts
chapterFlags: {
  well_stair_seen?: boolean;       // 见过井底楼梯
  well_name_lost?: boolean;        // 名字被井下世界取走
  dream_corruption?: number;       // 梦蚀污染
  forbidden_sentence?: boolean;    // 写下过禁句
  abyss_gaze?: number;             // 被海渊注视
  sea_called_name?: boolean;       // 听见海叫自己的名字
  dog_memory?: number;             // 狗子记得几次轮回
  dog_promise?: boolean;           // 与狗子立过约
  yomi_debt?: number;              // 黄泉债
  tsukumo_whisper?: number;        // 旧物低语程度
  hollow_boat_signal?: boolean;    // 收到空舟信号
}
```

### 1.3 篇章之间的交叉

篇章不必完全独立。建议允许以下交叉：

```text
《沉没异生篇》与《犬鸣永生篇》：狗子可能是把你从井下带回来的人。
《梦蚀篇》与《海渊篇》：梦里反复出现潮声，说明海渊已开始侵入。
《百年器物篇》与所有篇章：旧物可以保存上一轮人生的记忆。
《空舟来客篇》与《海渊篇》：空舟从海上漂来，但里面的文字来自井下。
```

## 2. 《沉没异生篇》

### 2.1 定位

```text
关键词：童年、废井、神隐、地下异乡、名字交换、回不去的家。
触发源：p_kid_well 沉没影深。
基调：异世界 + 黄泉 + 童年怪谈。
```

### 2.2 入口事件改造

原事件：村口废井，小伙伴打赌掀开井盖。

改造后：

```text
选择 A：用力掀开井盖
  普通失败：坠井重伤或死亡。
  运势较高：掉到井底，但井底没有水，只有一条向下的楼梯。
  若 creativity/luck 满足条件：进入《沉没异生篇》。

选择 B：算了，太危险了
  正常避险。
  若之前已触发 well_stair_seen：夜里梦见井盖自己打开。
```

### 2.3 篇章世界观

井下不是地下，而是“另一个新乡”。那里也有学校、街道、母亲、狗子，但每个人都没有影子。井下的人说：

```text
“上面才是井。你们一直住在井口。”
```

井下世界使用名字作为货币。玩家若想回到现实，必须交出一部分名字。名字被拿走后，现实中的某些人会逐渐叫错玩家，事件标题也可能出现错字。

### 2.4 分支剧情

#### 分支 A：立刻逃回现实

玩家拒绝井下人的帮助，沿楼梯向上爬。

结果：

```text
回到现实，但现实已经过去三天。
获得 flag：well_stair_seen。
属性：luck +，physique -，creativity +。
后续：青年期可能触发“井下明信片”事件。
```

后续事件：

```text
12 岁：你发现作文本里多了一段不是你写的文字。
20 岁：大学宿舍水房的下水口传来狗子的声音。
45 岁：你在医院电梯里按到了“-1 层”，但这栋楼没有地下室。
```

#### 分支 B：交出名字，换取才能

井下的书记官提出交易：交出名字中的一个字，换取某种能力。

选择：

```text
交出“聪” -> intelligence +20，但人际关系降低。
交出“明” -> luck +20，但人生关键事件出现异常。
交出“沉默” -> creativity +30，但现实中没人能完整听见你的话。
拒绝交易 -> 回到现实，保留完整自我。
```

结局可能：

```text
《无名归乡》：你活到晚年，但墓碑上缺了一个字。
《井下状元》：你在人生中大获成功，但所有奖状上的名字都不是你。
```

#### 分支 C：带一个井下人回现实

井下的“另一个狗子”请求你带他上去。

选择：

```text
带他走：现实中的狗子会开始记得不属于自己的事。
拒绝：狗子关系 -，但现实稳定。
让他替你走：玩家回不去，进入井下特殊结局。
```

后续可接《犬鸣永生篇》。

### 2.5 篇章结局

```text
结局 1：《出梦又生》
你回到现实，只损失数日时间。人生继续，但井口事件成为永久 flag。

结局 2：《无名归乡》
你回来了，但名字被井下取走。晚年结算时出现隐藏称号“无名之人”。

结局 3：《沉没永生》
你留在井下。现实中的你被判定失踪，游戏进入特殊死亡/神隐结局。

结局 4：《替身上岸》
你让井下的自己回到现实。后续人生继续，但玩家的属性和关系会发生大幅偏移。
```

## 3. 《梦蚀篇》

### 3.1 定位

```text
关键词：失眠、创作、梦境污染、禁句、被文字观看。
触发源：p_young_create、p_mid_overwork、p_young_night、低 luck + 高 creativity。
基调：克苏鲁 + 文学恐怖 + 精神污染。
```

### 3.2 入口条件

满足任一：

```text
creativity >= 70 且 luck <= 20。
连续 3 次选择熬夜/硬撑/通宵。
dream_corruption >= 3。
在 3:00 相关事件中选择继续创作。
```

入口提示：

```text
凌晨三点，你写下一句你不认识的句子。
它没有意义，但你知道它正在读你。
```

### 3.3 篇章世界观

梦不是睡眠产生的，而是一种外部寄生物。它靠人类未完成的作品生长。越有才脉的人，越容易被梦寄生。

玩家写下的文本会反向改变现实：

```text
写“雨停了”，第二天全城无雨。
写“狗子忘了我”，狗子真的少回了一条消息。
写“我没有出生”，母亲的相册里少了一张照片。
```

### 3.4 分支剧情

#### 分支 A：把梦写完

玩家决定完成那部梦中作品。

收益：

```text
creativity 大幅上升。
可能解锁特殊职业：梦译者 / 异常作家。
```

代价：

```text
dream_corruption 增加。
部分现实事件被梦替换。
```

后续：

```text
作品出版后，读者开始做同一个梦。
每获得一次成功，现实中少一个熟人记得你。
```

#### 分支 B：烧掉手稿

玩家试图切断污染。

结果：

```text
短期：dream_corruption -，physique +，creativity -。
后续：灰烬会出现在不同年龄段事件里。
```

隐藏条件：若 `tsukumo_whisper > 0`，烧掉的不是手稿，而是一个旧物的记忆，会接入《百年器物篇》。

#### 分支 C：让别人读

玩家把手稿交给编辑、老师、恋人或狗子。

分支：

```text
交给编辑：职业成功，但污染扩散。
交给恋人：爱情线异化，可能触发“梦中婚礼”。
交给狗子：狗子替你承担一部分梦蚀，接《犬鸣永生篇》。
```

### 3.5 篇章结局

```text
结局 1：《醒来的人》
你承认自己不是天才，只是被梦借用。才脉降低，但现实稳定。

结局 2：《梦中出版》
你成为知名作家，但所有读者梦见同一个黑色太阳。高星特殊结局。

结局 3：《第三小时》
你再也无法醒来。现实中的你被诊断为长期昏睡，进入梦中死亡结局。

结局 4：《代写者》
狗子或某个亲密关系替你写完最后一章。你存活，但欠下 dog_memory 或 yomi_debt。
```

## 4. 《海渊篇》

### 4.1 定位

```text
关键词：潮水、溺水、深海、龙宫时间错位、空舟信号、古老注视。
触发源：a_young_lost、p_young_tide、p_young_river、海边旅行事件。
基调：深海克苏鲁 + 浦岛式时间差 + 空舟传说。
```

### 4.2 入口事件改造

海边毕业旅行、赶海涨潮、急流救人都可以作为入口。

```text
当玩家濒临溺水时：
  普通情况：死亡或获救。
  若 luck 高：听见海底有人叫自己的名字。
  若 abyss_gaze >= 1：被拖入海渊篇。
```

### 4.3 篇章世界观

海底不是宫殿，而是一座正在腐烂的档案馆。每一个被海吞没的人，都会变成一份潮汐档案。海不是想杀玩家，而是想“登记”玩家。

空舟漂来，舱内有一位不会说话的少女。她递给玩家一张纸：

```text
“你的死亡日期写错了。”
```

### 4.4 分支剧情

#### 分支 A：接受海的登记

玩家把自己的名字写进潮汐档案。

收益：

```text
luck +，死亡时有一次被海退回现实的机会。
```

代价：

```text
sea_called_name = true。
晚年有概率触发“海来收账”。
```

#### 分支 B：带走空舟少女

玩家试图把空舟少女带回现实。

结果：

```text
她会成为一个短期 NPC，无法沟通，但会在危机时指向正确选项。
若照顾她：appearance/luck 上升。
若抛弃她：abyss_gaze 大幅增加。
```

后续：空舟少女可能不是人，而是“未来某次死亡后被海退回来的你”。

#### 分支 C：砸碎潮汐档案

玩家拒绝被海登记。

结果：

```text
短期逃脱。
但每一次下雨都可能触发海渊回响。
财富/职业事件可能被潮水破坏。
```

### 4.5 篇章结局

```text
结局 1：《退潮归人》
你被海退回现实，年龄增加 1~3 岁，失去一段记忆。

结局 2：《龙宫迟归》
你以为只在海底待了一夜，现实已经过去十年。直接跳到下一人生阶段。

结局 3：《潮汐档案》
你没有死亡，而是被记录为“已归档”。结算页显示非传统死亡。

结局 4：《空舟返航》
你与空舟少女交换位置。她替你回现实，你留在海上漂流。
```

## 5. 《犬鸣永生篇》

### 5.1 定位

```text
关键词：esu狗子、知己、轮回锚点、记忆保留、替死、约定。
触发源：关系线高好感、濒死次数、井下/梦蚀/海渊交叉事件。
基调：友情怪谈 + 轮回 + 温和恐怖。
```

### 5.2 入口条件

满足任一：

```text
confidant affinity >= 80。
nearDeathCount >= 2 且狗子关系未破裂。
玩家进入过隐藏篇章，且 dog_memory >= 1。
某次即死事件中，狗子出现并喊出玩家名字。
```

### 5.3 篇章世界观

狗子不是神，也不是怪物。他只是“上一轮唯一没有忘记你的人”。每当玩家死亡，狗子会丢失现实中的某些东西，换取保留一段记忆。

他记得越多，就越不像现实中的人。

### 5.4 分支剧情

#### 分支 A：相信狗子

狗子告诉玩家：

```text
“这个选项你上次选过。别选。”
```

玩家可以选择相信或不相信。

结果：

```text
相信：避开一次死亡，但 dog_memory +1。
不信：正常推进，可能死亡或进入其他篇章。
```

#### 分支 B：替狗子承担记忆

玩家发现狗子的异常来自轮回负担，可以选择把记忆拿回来。

收益：

```text
dog_memory -，关系大幅上升。
解锁上一轮人生片段。
```

代价：

```text
玩家获得混乱记忆，某些事件选项出现“上次你选过”的提示。
```

#### 分支 C：让狗子替死

在某次死亡事件中，狗子可以替玩家死亡。

结果：

```text
玩家存活，狗子从现实关系中消失。
所有与狗子相关的后续事件变成空白事件。
晚年可能触发“无人赴约”。
```

### 5.5 篇章结局

```text
结局 1：《约定仍在》
你和狗子都活到晚年。结算页增加高价值成就。

结局 2：《替你死过的人》
狗子替死，玩家存活但失去知己线。高痛感分支。

结局 3：《犬鸣永生》
狗子成为轮回锚点。重开后开局出现极短异常文本。

结局 4：《不再记得》
你选择让狗子忘记所有轮回。关系归零，但他终于成为普通人。
```

## 6. 《百年器物篇》

### 6.1 定位

```text
关键词：旧物、付丧神、遗物、手机、棋子、抽卡牌、被使用过的东西保存人生。
触发源：长期使用同一物品、晚年回顾、财富低但 creativity 高、抽卡历史。
基调：物哀 + 器物成精 + 记忆保存。
```

### 6.2 入口条件

```text
触发过 20 个以上人生事件。
eventLog 中某类事件反复出现。
财富低但 creativity 高。
结算前持有某个“旧物” flag。
```

可由以下现实事件引入：

```text
旧手机忽然收到十年前的短信。
围棋棋子在夜里自己移动。
小时候的校服口袋里出现一张还没抽过的运势卡。
病床旁的水杯说出了母亲的声音。
```

### 6.3 篇章世界观

物品不会说话，只会“替你记得”。当一个人反复遗忘、逃避、重开，旧物会积累那些被丢掉的版本。

### 6.4 分支剧情

#### 分支 A：听旧物说完

玩家听完旧物保存的上一轮记忆。

收益：

```text
获得关键事件预警。
解锁一个隐藏选项。
```

代价：

```text
tsukumo_whisper +。
现实文本偶尔出现物品视角。
```

#### 分支 B：丢掉旧物

玩家试图切断异常。

结果：

```text
现实稳定，异常降低。
但失去某些回忆与成就线索。
```

#### 分支 C：把旧物送给别人

玩家将旧物交给狗子、恋人、孩子或母亲。

结果：

```text
对应关系线获得保护。
但异常转移到对方身上。
```

### 6.5 篇章结局

```text
结局 1：《物仍记得》
玩家死亡后，旧物保留一段记忆，下一局可获得提示。

结局 2：《断舍离》
玩家清空所有旧物，现实稳定但失去隐藏篇章入口。

结局 3：《器物成人》
旧物成为新的 NPC，替代某个已经失去的人继续陪伴玩家。
```

## 7. 《空舟来客篇》

### 7.1 定位

```text
关键词：海上漂来空舟、无法沟通的少女、未知文字、外来者、稀人。
触发源：海边事件、晚年海渊回响、低 luck 高 intelligence。
基调：民俗科幻 + 稀人信仰 + 反向异世界。
```

### 7.2 入口事件

某一年暴雨后，河堤边发现一个椭圆形舱体。里面坐着一个少女，她不会说任何语言，只抱着一个盒子。盒子里不是宝物，而是玩家某一年死亡时的病历。

### 7.3 篇章世界观

空舟少女来自“玩家没有活下来的那条时间线”。她不属于这个世界，因此无法被多数人记住。

### 7.4 分支剧情

#### 分支 A：收留她

玩家把她带回家。

结果：

```text
短期 luck +，但家庭/社会压力增加。
她会在关键事件前做出无声预警。
```

#### 分支 B：报警/交给机构

现实理性处理。

结果：

```text
intelligence +，但 hollow_boat_signal 激活。
后续新闻里出现她失踪的消息。
```

#### 分支 C：把她送回海上

按传说处理，让空舟回到来处。

结果：

```text
abyss_gaze -。
但未来某次海边事件，她会再次出现，年龄没有变化。
```

### 7.5 篇章结局


## 8. 《黄泉债篇》

### 8.1 定位

```text
关键词：死亡边缘、黄泉、债务、返回代价、污秽与清洗。
触发源：任何一次本应死亡但被篇章系统转化的事件。
基调：黄泉神话 + 死亡交易 + 代价管理。
```

### 8.2 入口条件

```text
玩家触发即死事件，但满足特殊属性/篇章 flag，被允许“赊命”。
```

系统提示：

```text
你没有死。
但有人替你在死亡簿上签了延期。
```

### 8.3 篇章机制

新增变量：

```text
yomi_debt
```

每次从死亡边缘返回，`yomi_debt +1`。债越高，晚年越容易触发黄泉追债事件。

### 8.4 分支剧情

#### 分支 A：偿还黄泉债

通过失去属性、关系、记忆偿还。

```text
交出一段爱情记忆 -> yomi_debt -1，creativity -。
交出一次职业成功 -> yomi_debt -1，wealth -。
交出一个人的名字 -> yomi_debt -2，关系线断裂。
```

#### 分支 B：赖账

继续活，但黄泉追债加重。

```text
短期无损。
后续死亡事件概率增加。
晚年出现“门外有人清点你的年龄”。
```

#### 分支 C：找替身

玩家可以用某个篇章中的替身、空舟来客、井下自己偿还债务。

结果取决于道德选择：

```text
用替身偿债：存活但结局扣分。
拒绝替身：可能直接死亡，但解锁高价值成就。
```

### 8.5 篇章结局

```text
结局 1：《债清人归》
偿还所有黄泉债，正常死亡，结算评价提升。

结局 2：《延期人生》
活得很久，但每个重要关系都被拿走一部分。

结局 3：《替身入册》
别人替你死去，你继续人生，但某些结算文本会指认你。
```

## 11. 写作风格要求

篇章文本应保持克制，不做设定解释堆叠。

推荐文本风格：

```text
你看见井底有楼梯。
楼梯很干净，像每天都有人打扫。
最下面传来狗子的声音。
他说：“别下来。你上次就是从这里开始忘记自己的。”
```

避免：

```text
欢迎来到异世界大陆，这里有魔王、技能、等级和公会。
```

核心是：

```text
现实没有消失，只是从某个角度看，它开始露出背面。
```
